# Portafolio profesional

Este portafolio es una página personal para presentar mi perfil como Desarrollador Web y mostrar mis proyectos.

## Secciones principales
- **Inicio**: breve presentación y llamado a contacto.
- **Sobre mí**: habilidades y enfoque de aprendizaje.
- **Proyectos**: grilla responsiva con tarjetas de proyectos.
- **Formación**: (si aplica) formación/experiencia.
- **Contacto**: enlaces para comunicarme.

## Tecnologías
- HTML
- CSS (incluye CSS Grid y Media Queries)
- Bootstrap 
- SCSS
- SASS


## Objetivo
Que cualquier persona pueda entender rápidamente quién soy, ver ejemplos de mi trabajo y contactarme.
